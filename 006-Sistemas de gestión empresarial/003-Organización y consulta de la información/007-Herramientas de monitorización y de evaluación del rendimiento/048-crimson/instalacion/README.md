# Presets de instalación

- `erp-completo.json`: modelo ERP completo que ya incluía Crimson.
- `empresa-pequena.json`: modelo reducido para una pequeña empresa.

El instalador puede empezar vacío o cargar cualquiera de estos JSON. Una vez cargado, el modelo sigue siendo editable visualmente antes de crear la base `crimson` de JocarsaBBDD.
