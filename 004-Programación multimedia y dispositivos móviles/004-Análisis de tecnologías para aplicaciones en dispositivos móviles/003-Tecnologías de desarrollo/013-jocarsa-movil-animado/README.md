# jocarsa | móvil — navegación animada

Servidor HTTP: `python3 -m http.server 8000` y abrir http://localhost:8000.

Las vistas, controladores y templates se solicitan sin caché. La navegación entre pestañas aplica slide + fade según el orden de botones. Para cambios en CSS/JS principal, actualizar la versión `?v=3` y recargar.
