1. Componentes de estructura y maquetación
Son los componentes que organizan el documento.
Componente	Función
Página	Contenedor principal con tamaño A4, A3, carta, etc.
Sección	Agrupa componentes relacionados.
Contenedor	Agrupa elementos con estilos comunes.
Fila	Organiza elementos horizontalmente.
Columna	Organiza elementos verticalmente.
Cuadrícula	Distribuye elementos en filas y columnas.
Panel	Bloque visual con fondo, borde y espaciado.
Tarjeta	Contenedor para información destacada.
Pestañas	Organiza información en el editor o en documentos digitales.
Separador	Línea horizontal o vertical.
Espaciador	Introduce espacios entre elementos.
Salto de página	Fuerza el comienzo de una nueva página.
Salto de sección	Divide el documento en secciones independientes.
Cabecera de página	Elementos repetidos en todas las páginas.
Pie de página	Información repetida al final de cada página.
Marca de agua	Texto o imagen de fondo.

2. Componentes de texto
Componente	Función
Título	Título principal del documento.
Subtítulo	Título secundario.
Encabezado	Títulos de secciones y subsecciones.
Párrafo	Bloque de texto normal.
Texto enriquecido	Texto con negrita, cursiva, colores, enlaces, etc.
Etiqueta	Nombre de un campo.
Valor	Contenido de un campo.
Etiqueta + valor	Ejemplo: Cliente: Empresa S.L.
Lista con viñetas	Enumeración de elementos.
Lista numerada	Enumeración ordenada.
Cita	Texto destacado.
Nota	Información complementaria.
Nota al pie	Aclaraciones al final de la página.
Texto legal	Condiciones y cláusulas.
Texto dinámico	Texto procedente de una base de datos.
Texto condicional	Texto que aparece según determinadas reglas.

3. Componentes tabulares
Fundamentales para facturas, actas, balances, inventarios y listados.
Componente	Función
Tabla simple	Filas y columnas de datos.
Tabla dinámica	Columnas y filas generadas automáticamente.
Tabla agrupada	Agrupa registros por categorías.
Tabla jerárquica	Filas con niveles y subniveles.
Tabla pivote	Agrupaciones y agregaciones de datos.
Matriz	Cruce de dos dimensiones, como alumnos y asignaturas.
Tabla comparativa	Comparación entre períodos o entidades.
Tabla de totales	Subtotales, impuestos y totales.
Tabla de frecuencias	Distribución estadística.
Tabla calendario	Datos organizados por fechas.
Tabla de doble entrada	Cruce de variables.
Tabla con celdas fusionadas	Permite combinar filas y columnas.
Tabla con formato condicional	Colores según los valores.
Tabla con fórmulas	Cálculos entre columnas o celdas.

Estos permiten crear documentos que cambian según el registro seleccionado.
Componente	Función
Campo de texto	Nombre, descripción, dirección, etc.
Campo numérico	Cantidades y valores.
Campo monetario	Importes con moneda.
Campo de fecha	Fecha con formato configurable.
Campo de hora	Horas y minutos.
Campo de duración	Tiempo transcurrido.
Campo booleano	Sí/no, verdadero/falso.
Casilla de verificación	Selección o confirmación.
Campo de selección	Valor de una lista.
Campo calculado	Resultado de una fórmula.
Campo relacionado	Dato de otra entidad.
Campo agregado	SUM, AVG, COUNT, MIN, MAX.
Campo condicional	Valor calculado según una condición.
Campo de referencia	Identificador, código o número de expediente.
Campo de porcentaje	Porcentajes con formato.

8. Componentes específicos de documentos oficiales
Componente	Función
Bloque de emisor	Datos de empresa, centro o institución.
Bloque de destinatario	Datos de cliente, alumno o empleado.
Bloque de identificación	Número, referencia y fecha.
Bloque de facturación	Base imponible, impuestos, descuentos y total.
Bloque de pago	Cuenta bancaria, vencimiento y forma de pago.
Bloque de calificaciones	Asignaturas, notas y resultados.
Bloque de asistencia	Presencias, ausencias y porcentajes.
Bloque de firmas	Firmantes, cargos, fechas y firmas.
Bloque de aprobación	Conforme, aprobado, rechazado.
Bloque de certificación	Texto de certificación y autoridad emisora.
Bloque de condiciones	Condiciones contractuales o comerciales.
Bloque de observaciones	Comentarios y anotaciones.
Bloque de validación	Código de verificación o CSV administrativo.

Estos bloques deberían ser componentes compuestos, construidos a partir de los componentes básicos, no implementaciones independientes.
9. Componentes avanzados de composición
Son especialmente importantes si el diseñador va a generar documentos automáticamente a partir de JocarsaBBDD u otras fuentes de datos.
Componente	Función
Repetidor	Repite un bloque por cada registro.
Agrupador	Agrupa registros por un campo.
Condicional	Muestra u oculta elementos según una regla.
Filtro	Selecciona los registros que aparecen.
Ordenador	Ordena registros por uno o varios campos.
Calculadora	Evalúa fórmulas.
Acumulador	Calcula totales progresivos.
Subtotalizador	Genera subtotales por grupo.
Selector de origen	Conecta un componente con una entidad o consulta.
Referencia cruzada	Inserta valores de otros bloques.
Plantilla anidada	Incluye un documento o bloque reutilizable.
Subinforme	Inserta un informe dentro de otro.
Índice automático	Genera un índice de contenidos.
Numerador	Numera páginas, registros o apartados.
Repetidor de cabecera	Repite encabezados de tablas al cambiar de página.

10. Componentes de paginación e impresión
Componente	Función
Configuración de página	Tamaño, orientación y márgenes.
Numeración de páginas	Página X de Y.
Salto de página automático	Distribuye el contenido entre páginas.
Control de bloques indivisibles	Evita cortar firmas o tarjetas.
Control de viudas y huérfanas	Evita líneas aisladas.
Encabezado repetido de tabla	Mantiene los títulos entre páginas.
Área imprimible	Define límites de impresión.
Escalado de impresión	Ajusta el documento a A4, A3, etc.
Exportación	PDF, HTML, DOCX, XLSX, CSV.
