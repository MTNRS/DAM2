Mensajes emergentes

Pulsa cada botón para comprobar los cuatro estados. Se pueden cerrar manualmente y desaparecen automáticamente.

Uso

Éxito para operaciones completadas, información para feedback neutral, aviso cuando conviene revisar algo y error cuando una operación no se completa.

Comportamiento

Los mensajes se apilan en la esquina inferior derecha, admiten cierre manual y se eliminan automáticamente a los cinco segundos.
