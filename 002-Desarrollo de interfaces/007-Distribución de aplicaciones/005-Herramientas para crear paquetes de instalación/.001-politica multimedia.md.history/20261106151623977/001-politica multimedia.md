# 7. Marketing audiovisual de JOCARSA

Objetivo: mostrar el software funcionando, demostrar capacidades técnicas y convertir esas demostraciones en oportunidades comerciales.

Para JOCARSA, el marketing audiovisual debería basarse en una idea: no contar lo que hace el software, sino enseñar cómo funciona y qué problemas resuelve.

La ventaja de JOCARSA es que dispone de aplicaciones reales y desarrollos propios. Esto permite generar contenido audiovisual directamente a partir del producto, sin depender de campañas publicitarias tradicionales.

## 3. El sistema de producción audiovisual

No produciría cada vídeo manualmente desde cero. En JOCARSA desarrollaría un sistema semiautomatizado de generación audiovisual, aprovechando Python, Playwright y FFmpeg.

La automatización debería controlar los clics, esperas, desplazamientos y cambios de pantalla. Para cada grabación utilizaría un entorno de demostración con datos ficticios y sin operaciones destructivas.

## 4. Identidad audiovisual corporativa

Los vídeos deberían ser reconocibles como contenido de JOCARSA incluso sin mostrar continuamente el logotipo.

Definiría una plantilla audiovisual con estas características:

- Esquinas achaflanadas, no redondeadas, en rótulos, marcos y elementos gráficos.
- Tipografía, colores y logotipo coherentes con jocarsa.com.
- Cabecera breve, de 1–2 segundos como máximo.
- Zoom suave sobre la funcionalidad que se está explicando.
- Subtítulos para reproducción sin sonido.
- Cierre con el nombre del producto y su URL.
- Preferencia por mostrar interfaces reales frente a animaciones decorativas.

## 10. La oportunidad específica de JOCARSA

Dado que JOCARSA ya está desarrollando herramientas para generar documentación comercial, manuales, publicaciones para redes y artículos de blog a partir del código de sus proyectos, el siguiente paso lógico es incorporar la generación audiovisual a esa misma cadena de producción.

La idea sería que cada proyecto dispusiera de una carpeta `doc/video/` con un guion de demostración, escenarios Playwright, grabaciones originales, vídeos editados y versiones para redes.

De esta manera, cuando se lance una nueva aplicación o una funcionalidad importante, el proceso podría producir de forma semiautomática su documentación y sus materiales audiovisuales.

La política audiovisual que establecería para JOCARSA es: cada producto debe poder verse funcionando antes de que el cliente tenga que solicitar una reunión. Y cada nueva funcionalidad relevante debería ser una oportunidad para producir contenido comercial reutilizable.
