# Medidas de usabilidad y accesibilidad de las aplicaciones
* Medidas de usabilidad

  * Tiempo necesario para aprender a usar la aplicación
  * Tiempo para completar una tarea
  * Número de acciones necesarias
  * Número de errores cometidos
  * Tiempo de recuperación ante errores
  * Porcentaje de tareas completadas correctamente
  * Facilidad para recordar el funcionamiento
  * Grado de satisfacción del usuario
* Medidas de accesibilidad

  * Navegación completa mediante teclado
  * Compatibilidad con lectores de pantalla
  * Contraste suficiente entre texto y fondo
  * Legibilidad y tamaño del texto
  * Posibilidad de ampliar el contenido
  * Disponibilidad de textos alternativos
  * Disponibilidad de subtítulos y transcripciones
  * Uso correcto de etiquetas en formularios
  * Orden lógico de navegación y foco
  * Uso de HTML semántico
  * No depender exclusivamente del color
  * Cumplimiento de estándares de accesibilidad como WCAG
