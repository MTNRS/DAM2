Divisón de objetivos de la WCAG en:

Percibibles
Operables
Comprensibles
Robustos

Tres nives de cumplimiento:
Nivel A: Fácil y casi obligatorio
Nivel AA: Algo más complejo y recomendable
Nivel AAA: Difícil pero deseable


Medidas:
Garantizar contraste mínimo
Garantizar contraste mínimo de 4,5:1 en texto normal y 3:1 en texto grande
Permitir ampliar el texto al 200 % sin pérdida de contenido
Evitar pérdida de contenido al visualizar la web a 320 píxeles CSS de ancho
Permitir modificar el espaciado del texto sin romper el diseño

Permitir manejar toda la web utilizando exclusivamente el teclado
Evitar bloqueos de teclado en modales y componentes
Mostrar claramente qué elemento tiene el foco
Evitar que el foco quede completamente oculto por otros elementos
Incluir un enlace para saltar al contenido principal
Usar títulos de página descriptivos - title
Mantener un orden lógico de navegación con Tab
Usar nombres de enlaces y botones que expliquen su función
Evitar destellos que puedan provocar convulsiones

Permitir cancelar o deshacer acciones de puntero cuando corresponda
Ofrecer alternativas a interacciones que requieren arrastrar elementos
Garantizar objetivos táctiles de al menos 24 × 24 píxeles CSS o excepciones válidas

Declarar correctamente el idioma del documento HTML
Utilizar etiquetas visibles para identificar los campos
Identificar los campos obligatorios
Mostrar errores de validación mediante mensajes de texto
Proporcionar sugerencias para corregir errores cuando sea posible

Evitar cambios inesperados al recibir foco o cambiar un valor
Mantener la navegación y la identificación de componentes coherentes
