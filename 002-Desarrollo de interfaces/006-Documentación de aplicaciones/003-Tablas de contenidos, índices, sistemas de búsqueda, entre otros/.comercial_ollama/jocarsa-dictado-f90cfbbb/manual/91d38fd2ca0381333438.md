### Interfaz de usuario

#### Indicadores de carga animados
**Para qué sirve:** Muestra indicadores visuales para mostrar el progreso del procesamiento de la transcripción y la generación de respuestas.

**Cómo utilizarla:** Cuando estés utilizando la aplicación, verás indicadores que se muestran automáticamente mientras tu archivo de audio se está transcribiendo o cuando se están generando las respuestas. No es necesario realizar ninguna acción específica para activar estos indicadores; simplemente aparecerán en pantalla durante el proceso.

**Resultado esperado:** Verás animaciones y barras de progreso que te informan sobre la etapa actual del procesamiento, ayudándote a entender cuánto tiempo queda hasta completarse.

---

#### Tema oscuro
**Para qué sirve:** Mantiene un tema oscuro en la interfaz de usuario para mejorar la comodidad visual durante el uso nocturno o en entornos con poca luz.

**Cómo utilizarla:** Los usuarios pueden activar este modo desde las opciones del menú. Una vez que lo habilitas, toda la aplicación cambiará a un esquema de colores oscuro para proporcionarte una experiencia más cómoda y menos agresiva visualmente.

**Resultado esperado:** La interfaz de usuario adoptará un tema oscuro con tonos azules oscuros, mejorando así la legibilidad y el confort visual durante su uso en condiciones de poca luz.
