### Indicadores de procesamiento

#### Mostrar indicadores de trabajo asíncrono

**Para qué sirve:**
Este indicador te ayuda a saber el estado del procesamiento asíncrono en tiempo real. Cuando realizas una acción que lleva tiempo, como subir un archivo grande o realizar una búsqueda extensa, este indicador aparecerá para mostrarte que la tarea está en proceso.

**Cómo utilizarla:**
No es necesario que hagas nada específico para activar esta función; simplemente se mostrará automáticamente cuando el sistema esté procesando información de manera asíncrona. No hay pasos específicos que debas seguir, ya que este indicador es automático y no requiere interacción directa por tu parte.

**Resultado esperado:**
Cuando el sistema está procesando una tarea en segundo plano, verás un indicador visual (como un spinner o icono de carga) que indica que la operación está en curso. Este indicador desaparecerá automáticamente cuando la tarea haya finalizado.
