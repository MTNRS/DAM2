### Base de datos SQLite

#### Conservación de la base de datos existente
**Para qué sirve:** Esta función te permite mantener tu base de datos SQLite actual sin perder los datos importantes durante el proceso de actualización del software. Es útil para asegurarte de que tus datos antiguos no se borren o corrompan cuando instales nuevas versiones.

**Cómo utilizarla:** Los pasos exactos no están documentados en la evidencia disponible, pero conceptualmente puedes esperar que haya una opción o configuración específica dentro del software que te permita seleccionar si deseas conservar tu base de datos existente durante las actualizaciones. Esto podría ser un marcador de preferencias o una opción en el menú de configuración.

**Resultado esperado:** Después de habilitar esta función, cuando realices la actualización del software, tu base de datos SQLite se mantendrá intacta y tus datos antiguos no deberían verse afectados.
