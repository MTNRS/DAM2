### Procesamiento

#### Indicador de procesamiento
**Para qué sirve:** Este indicador visual te ayuda a saber cuándo se está realizando una operación importante, como la transcripción o el formateo. Mientras esté activo, sabrás que el sistema está trabajando en tu solicitud.

**Cómo utilizarla:** No necesitas hacer nada para usar este indicador. Simplemente aparecerá automáticamente cuando el sistema esté procesando tus datos.

**Resultado esperado:** Verás un icono o una barra de progreso que indica que la operación está en curso. Este indicador desaparecerá una vez que la transcripción o formateo haya terminado correctamente.

---

Recuerda, si ves este indicador, simplemente espera pacientemente mientras el sistema finaliza su tarea.
