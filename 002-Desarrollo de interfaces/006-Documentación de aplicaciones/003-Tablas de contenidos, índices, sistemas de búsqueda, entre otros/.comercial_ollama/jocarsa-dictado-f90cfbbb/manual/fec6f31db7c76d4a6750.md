### Instalación nueva

**Para qué sirve:**  
El proceso de instalación para nuevos usuarios te permite configurar el sistema jocarsa-dictado desde cero. Al finalizar la instalación, tendrás una base de datos SQLite ya poblada con 16 ejemplos ficticios que puedes usar como punto de partida.

**Cómo utilizarla:**  
Aunque no tengo los detalles exactos sobre cómo realizar cada paso en este momento, te guío conceptualmente sobre lo que podrías esperar:

- Primero, asegúrate de tener todos los requisitos del sistema instalados. Esto incluye el entorno de desarrollo y cualquier otra herramienta necesaria para ejecutar jocarsa-dictado.
- Luego, descarga o clona el repositorio del proyecto en tu máquina local.
- Ejecuta el script de instalación proporcionado por el equipo de desarrollo. Este script debería configurar automáticamente la base de datos SQLite y poblarla con los ejemplos ficticios.

**Resultado esperado:**  
Al finalizar, deberías tener un sistema jocarsa-dictado funcionando correctamente en tu entorno local. La base de datos estará lista para ser utilizada, incluyendo 16 registros de ejemplo que puedes revisar y modificar según sea necesario.

*Nota: Los pasos exactos no están documentados en la evidencia disponible.*
