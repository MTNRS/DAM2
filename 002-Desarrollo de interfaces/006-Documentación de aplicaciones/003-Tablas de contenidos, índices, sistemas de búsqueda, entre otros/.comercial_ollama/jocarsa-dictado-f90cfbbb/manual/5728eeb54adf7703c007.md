### Gestión de mensajes

#### Guardar mensajes
**Para qué sirve:** Esta función te permite guardar tanto los mensajes formateados como sus versiones originales en la base de datos del sistema. Al hacerlo, aseguras que tus conversaciones y comunicaciones estén almacenadas para su uso futuro.

**Cómo utilizarla:** 
1. Una vez que hayas terminado de redactar o recibir un mensaje, el sistema te permitirá guardar este mensaje automáticamente.
2. Si necesitas guardar manualmente, busca la opción en el menú o botón dedicado a esta acción y selecciona "Guardar".

**Resultado esperado:** El mensaje se guardará correctamente en la base de datos del sistema.

---

#### Eliminar mensajes
**Para qué sirve:** Esta función te permite eliminar mensajes específicos que ya no necesitas, liberando espacio en el sistema y manteniendo tu lista de mensajes organizada.

**Cómo utilizarla:**
1. Encuentra el mensaje que deseas eliminar.
2. Selecciona la opción o botón correspondiente para borrar este mensaje.

**Resultado esperado:** El mensaje será eliminado de la base de datos del sistema.

---

#### Abrir y editar mensajes
**Para qué sirve:** Esta función te permite abrir cualquier mensaje previamente guardado en el sistema y hacer los cambios necesarios, como corregir errores o actualizar información.

**Cómo utilizarla:**
1. Busca el mensaje que deseas editar.
2. Selecciona la opción para abrir este mensaje.
3. Realiza las modificaciones necesarias dentro del editor de texto.
4. Guarda tus cambios una vez terminado.

**Resultado esperado:** El mensaje se abrirá y podrás hacer los ajustes necesarios, luego será guardado con tus nuevas ediciones.

---

#### Buscar mensajes
**Para qué sirve:** Esta función te permite buscar rápidamente cualquier mensaje en tu lista basándote en un término específico, como una palabra clave o frase.

**Cómo utilizarla:**
1. Escribe el término de búsqueda que deseas usar.
2. El sistema mostrará los resultados relacionados con tu búsqueda.

**Resultado esperado:** Se te presentará una lista de mensajes que contienen el término de búsqueda que ingresaste.
