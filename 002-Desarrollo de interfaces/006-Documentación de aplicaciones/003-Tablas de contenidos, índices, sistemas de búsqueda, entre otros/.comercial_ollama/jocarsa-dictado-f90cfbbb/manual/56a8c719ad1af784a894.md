### Diagnóstico

#### Listado de modelos Ollama
**Para qué sirve:** Este comando te permite ver una lista completa de los modelos disponibles en el sistema Ollama.

**Cómo utilizarla:** Ejecuta el siguiente comando en la línea de comandos:
```
ollama list
```

**Resultado esperado:** Se mostrará una lista detallada con todos los modelos que están configurados y disponibles para usar en tu sistema.

---

#### Estado de procesos Ollama
**Para qué sirve:** Este comando te ayuda a verificar el estado actual de los procesos relacionados con Ollama, lo cual es útil para monitorear la salud del sistema.

**Cómo utilizarla:** Ejecuta el siguiente comando en la línea de comandos:
```
ollama ps
```

**Resultado esperado:** Se mostrará información sobre los procesos activos que están corriendo en tu sistema Ollama, incluyendo su estado y otros detalles relevantes.

---

#### Prueba de API tags
**Para qué sirve:** Este comando te permite probar la funcionalidad de la API de etiquetas (tags) para asegurarte de que está funcionando correctamente.

**Cómo utilizarla:** Ejecuta el siguiente comando en la línea de comandos:
```
curl http://127.0.0.1:11434/api/tags
```

**Resultado esperado:** Se mostrará una respuesta JSON con los datos de las etiquetas que la API ha recuperado, confirmando así su funcionamiento.

---

#### Configuración de modelo Ollama
**Para qué sirve:** Este comando te permite establecer el modelo específico que deseas utilizar en tu sistema Ollama.

**Cómo utilizarla:** Ejecuta el siguiente comando en la línea de comandos:
```
OLLAMA_MODEL=your-model-name python3 app.py
```

Reemplaza `your-model-name` con el nombre del modelo que quieres configurar. Por ejemplo, si estás usando un modelo llamado "model1", tu comando sería:
```
OLLAMA_MODEL=model1 python3 app.py
```

**Resultado esperado:** El sistema Ollama se iniciará utilizando el modelo especificado en la configuración.

---

#### Registro de errores
**Para qué sirve:** Este registro te permite ver cualquier error que ocurra durante la ejecución del sistema, tanto desde la consola Flask como a través de la interfaz de usuario (UI).

**Cómo utilizarla:** No es necesario realizar ninguna acción específica para este registro; simplemente asegúrate de estar monitoreando la consola y la UI mientras usas el sistema.

**Resultado esperado:** Cualquier error que ocurra será registrado en la consola Flask y también se mostrará en la interfaz de usuario, permitiéndote verlo y actuar en consecuencia.
