### Flask

#### Desarrollo de aplicaciones web
**Para qué sirve:** Este módulo te permite crear y ejecutar aplicaciones web de manera rápida y sencilla, ideal para desarrolladores que buscan una solución ligera y flexible.

**Cómo utilizarla:**
1. Asegúrate de tener instalado Flask en tu entorno de desarrollo. Puedes verificar esto revisando el archivo `requirements.txt` donde debería aparecer la línea `Flask>=3.0,<4`.
2. Una vez que tienes Flask configurado, puedes comenzar a crear tus vistas y rutas para manejar las peticiones HTTP.
3. Ejecuta tu aplicación web localmente para probarla antes de desplegarla en un entorno de producción.

**Resultado esperado:** Al finalizar, deberías tener una aplicación web funcional que responde a solicitudes desde el navegador o cualquier cliente HTTP.
