### app.py

#### Manejo de excepciones generales
**Para qué sirve:** Esta función maneja cualquier error que no sea un error HTTP y devuelve una respuesta JSON con detalles sobre el error.

**Cómo utilizarla:** No es necesario realizar acciones específicas para usar esta funcionalidad, ya que se activa automáticamente cuando ocurre un error no HTTP en la aplicación.

**Resultado esperado:** Se obtiene una respuesta JSON que indica que hubo un problema y proporciona información adicional sobre el tipo de error ocurrido. La respuesta incluirá un estado 'ok' falso y un mensaje de error específico.

---

#### Abrir Chrome cuando el servidor está listo
**Para qué sirve:** Lanza Google Chrome en una nueva ventana con la URL del servidor Flask una vez que este esté aceptando conexiones.

**Cómo utilizarla:** No es necesario realizar acciones específicas para usar esta funcionalidad, ya que se activa automáticamente cuando el servidor Flask está listo y disponible.

**Resultado esperado:** Se abre una nueva pestaña en Google Chrome con la URL del servidor Flask. Si no se encuentra Chrome, se abrirá el navegador web predeterminado.

---

#### Verificación de disponibilidad del servidor Flask
**Para qué sirve:** Intenta conectarse al servidor Flask hasta 100 veces con un intervalo de 0.1 segundos entre cada intento para asegurar que está disponible antes de proceder a abrir Chrome.

**Cómo utilizarla:** No es necesario realizar acciones específicas para usar esta funcionalidad, ya que se activa automáticamente cuando el servidor Flask está listo y disponible.

**Resultado esperado:** El sistema verifica la disponibilidad del servidor Flask hasta 100 veces. Si no puede conectarse después de estos intentos, registra una advertencia.

---

#### Registro de advertencia si Flask no está disponible
**Para qué sirve:** Registra una advertencia en el logger si Flask no está disponible después de 100 intentos de conexión.

**Cómo utilizarla:** No es necesario realizar acciones específicas para usar esta funcionalidad, ya que se activa automáticamente cuando el servidor Flask no responde tras los intentos de conexión.

**Resultado esperado:** Se registra una advertencia en el sistema indicando que Flask no está disponible y que Chrome no se abrirá.
