### Instalación

#### Actualización del software

**Para qué sirve:**  
Esta función te permite actualizar la aplicación desde la versión 10 a la versión 11. Es importante realizar esta actualización para acceder a las nuevas características y mejoras incluidas en la versión más reciente.

**Cómo utilizarla:**
1. **Respalda tu base de datos SQLite:** Antes de proceder con la actualización, es fundamental hacer una copia de seguridad de tu base de datos SQLite para evitar cualquier pérdida de información.
2. **Sustituye el archivo `app.py`:** Reemplaza el archivo `app.py` que viene en la versión 10 por el correspondiente a la versión 11.
3. **Reinicia Flask:** Finalmente, reinicia el servidor Flask para aplicar los cambios.

**Resultado esperado:**
Después de seguir estos pasos, deberías poder acceder a la nueva versión del software sin problemas y disfrutar de todas las mejoras que ofrece la versión 11.

---

Recuerda siempre realizar copias de seguridad antes de hacer cualquier tipo de actualización para proteger tus datos importantes.
