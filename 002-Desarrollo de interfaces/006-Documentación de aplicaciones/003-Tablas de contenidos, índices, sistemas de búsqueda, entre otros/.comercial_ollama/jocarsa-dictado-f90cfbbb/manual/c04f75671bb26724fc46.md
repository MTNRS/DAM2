### Formateo de texto

#### Formatear el texto transcribido

**Para qué sirve:**
Esta función te permite convertir el texto que has transcritos en un formato específico, como por ejemplo un correo electrónico. Utiliza la tecnología Ollama para generar automáticamente este nuevo formato a partir del texto original.

**Cómo utilizarla:**
1. Transcribe o ingresa el texto que deseas formatear.
2. Selecciona la opción de formateo adecuada (por ejemplo, "Formato de correo electrónico").
3. El sistema generará un nuevo documento con el formato seleccionado aplicado al texto original.

**Resultado esperado:**
El texto transcribido se transformará en un documento que sigue las reglas del formato elegido. Por ejemplo, si has seleccionado el formato de correo electrónico, el texto será reorganizado para incluir elementos típicos como encabezados, saludos y firmas.

---

**Nota:** Los pasos exactos no están documentados en la evidencia disponible. Sin embargo, puedes esperar que el proceso sea intuitivo y fácil de usar una vez que hayas transcritos tu texto.
