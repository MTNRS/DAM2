### app.py

**Transcripción de audio a texto**

- **Para qué sirve:** Permite convertir archivos de audio en formato WAV a texto.
- **Cómo utilizarla:** Sube un archivo de audio en formato WAV al sistema. El proceso de transcripción se realiza automáticamente una vez que el archivo es cargado.
- **Resultado esperado:** Se genera un texto que representa el contenido del audio.

**Generación de asunto y cuerpo de correo electrónico**

- **Para qué sirve:** Crea un asunto y cuerpo para un correo electrónico basándose en la transcripción proporcionada.
- **Cómo utilizarla:** Proporciona una transcripción como entrada al sistema. El sistema generará automáticamente el asunto y el cuerpo del correo electrónico.
- **Resultado esperado:** Se genera un asunto y un cuerpo de correo electrónico adecuados para la transcripción dada.

**Almacenamiento de mensajes en base de datos**

- **Para qué sirve:** Guarda las transcripciones, los asuntos y los cuerpos de los correos electrónicos en una base de datos SQLite.
- **Cómo utilizarla:** El sistema maneja automáticamente el almacenamiento de la información en la base de datos después de procesarla.
- **Resultado esperado:** Los detalles del mensaje se almacenan correctamente en la base de datos.

**Manejo de modelos Ollama**

- **Para qué sirve:** Permite cargar y descargar el modelo Ollama para generar respuestas basadas en prompts.
- **Cómo utilizarla:** El sistema maneja automáticamente la carga y descarga del modelo según sea necesario durante el proceso.
- **Resultado esperado:** El modelo Ollama está disponible cuando se necesita para procesar solicitudes.

**Comparación de tokens lexicales**

- **Para qué sirve:** Compara los tokens lexicales de una transcripción original con su versión procesada para asegurar la fidelidad del texto.
- **Cómo utilizarla:** Se realiza automáticamente durante el proceso de formateo y verificación del texto.
- **Resultado esperado:** Se garantiza que el texto procesado es fiel a la transcripción original.

**Formateo literal de texto**
