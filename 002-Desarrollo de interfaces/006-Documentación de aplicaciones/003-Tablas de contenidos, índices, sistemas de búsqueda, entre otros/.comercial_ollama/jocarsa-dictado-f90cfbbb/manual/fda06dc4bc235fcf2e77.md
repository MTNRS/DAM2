### Incorporación de ejemplos

#### Adición de mensajes demostrativos a la base existente

**Para qué sirve:**
Esta función te permite añadir 16 ejemplos ficticios a tu base de datos actual sin duplicar ningún mensaje ya presente en ella. Esto es útil para probar y familiarizarte con el funcionamiento del sistema antes de cargar tus propios mensajes.

**Cómo utilizarla:**
Para usar esta funcionalidad, sigue estos pasos:

1. Asegúrate de tener acceso a la línea de comandos o terminal donde estás trabajando.
2. Ejecuta el siguiente comando:
   ```
   python3 seed_demo.py
   ```

**Resultado esperado:**
Después de ejecutar el comando, deberías ver un mensaje en la consola indicándote que los 16 ejemplos ficticios se han añadido correctamente a tu base de datos. No habrá duplicados si ya existen mensajes similares.

---

Recuerda que estos pasos están basados en la evidencia disponible y pueden variar según cómo esté configurado tu entorno específico. Si encuentras problemas o necesitas más ayuda, consulta el archivo `README.md` para obtener información adicional.
