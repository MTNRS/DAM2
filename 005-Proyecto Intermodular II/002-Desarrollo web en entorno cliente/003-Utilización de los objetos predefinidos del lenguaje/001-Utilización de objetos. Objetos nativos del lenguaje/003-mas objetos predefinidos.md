| Objeto | Para qué sirve | Ejemplo |
|---|---|---|
| `Date` | Fechas y horas | `new Date()` |
| `Math` | Operaciones matemáticas | `Math.random()` |
| `String` | Trabajar con texto | `"hola".toUpperCase()` |
| `Number` | Trabajar con números | `Number.isInteger(5)` |
| `Array` | Listas de elementos | `[1,2,3].push(4)` |
| `Object` | Objetos y estructuras | `Object.keys(persona)` |
| `Boolean` | Valores booleanos | `Boolean(1)` |
| `JSON` | Convertir objetos ↔ texto JSON | `JSON.stringify(objeto)` |
| `RegExp` | Expresiones regulares | `/hola/.test(texto)` |
| `Set` | Colecciones sin duplicados | `new Set([1,2,2,3])` |
| `Map` | Colecciones clave → valor | `new Map()` |
| `Promise` | Operaciones asíncronas | `new Promise(...)` |
| `Error` | Representar errores | `new Error("Error")` |
| `BigInt` | Enteros enormes | `123456789n` |
