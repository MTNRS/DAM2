# Componentes de una interfaz web.

Una **interfaz web** suele estar formada por varios tipos de componentes que permiten **mostrar información, navegar, introducir datos y ejecutar acciones**. Una clasificación bastante completa sería:

* **Estructura y maquetación**: cabecera (`header`), pie (`footer`), contenido principal (`main`), secciones, columnas, contenedores, barras laterales (`sidebar`), paneles y rejillas (`grid`).
* **Navegación**: menú principal, menú lateral, submenús, breadcrumbs o migas de pan, pestañas (`tabs`), paginación, enlaces y botones de volver/avanzar.
* **Texto y contenido**: títulos, subtítulos, párrafos, etiquetas, listas, citas, bloques de código, iconos, imágenes, vídeos y audio.
* **Botones y acciones**: botón primario, secundario, cancelar, guardar, eliminar, editar, descargar, compartir, botones con iconos, botones flotantes y grupos de botones.
* **Formularios**: campos de texto, contraseña, email, número, fecha y hora, `textarea`, checkbox, radio button, select, multiselect, sliders, interruptores (`switch`), selector de archivos, selector de color y botones de envío.
* **Visualización de datos**: tablas, tarjetas (`cards`), listas, badges, estadísticas, indicadores KPI, barras de progreso, gráficos, calendarios, timelines y árboles jerárquicos.
* **Feedback al usuario**: alertas, mensajes de éxito/error/aviso, notificaciones, `toast`, loaders, spinners, skeletons, barras de progreso y estados vacío (`empty state`).
* **Elementos flotantes**: ventanas modales, diálogos de confirmación, popovers, tooltips, menús contextuales y desplegables.
* **Búsqueda y filtrado**: buscador, filtros, ordenación, autocompletado, chips de filtros activos y selectores de rango.
* **Identidad y usuario**: logo, avatar, perfil, menú de usuario, login, registro, recuperación de contraseña y selector de idioma/tema.
* **Componentes avanzados**: editor de texto, editor de código, drag & drop, árbol de archivos, mapas, chat, reproductores multimedia, kanban, calendario interactivo y dashboards.

**componentes de navegación, entrada, salida, acción, feedback, contenedores y visualización de datos**. Esa clasificación permite analizar prácticamente cualquier interfaz web.
