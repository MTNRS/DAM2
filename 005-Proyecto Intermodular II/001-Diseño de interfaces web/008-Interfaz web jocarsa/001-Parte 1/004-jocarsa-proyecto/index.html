PREGUNTAS FRECUENTES

Antes de empezar

¿Podéis adaptar un producto a nuestra empresa?

Sí. Podemos estudiar la adaptación de funcionalidades, interfaces, integraciones y flujos de trabajo.

¿Se puede ejecutar la inteligencia artificial en servidores propios?

Disponemos de experiencia en modelos locales. La viabilidad depende del modelo, el hardware, el volumen de datos y los requisitos de seguridad.

¿Ofrecéis formación para el equipo?

La formación tecnológica es una línea de actividad de JOCARSA y puede acompañar la implantación de software.

¿Cómo comienza un proyecto?

Con una conversación sobre objetivos, procesos actuales, requisitos y alcance. Después se puede preparar una propuesta.
