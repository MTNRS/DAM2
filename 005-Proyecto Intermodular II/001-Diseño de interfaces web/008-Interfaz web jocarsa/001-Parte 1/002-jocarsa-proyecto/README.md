# jocarsa | proyecto — rediseño de demostración

Se ha reemplazado el contenido editorial de Tragaluz por contenido demostrativo de JOCARSA. Se conserva la portada con vídeo a pantalla completa y controles nativos. **Importante:** el vídeo remoto original de Tragaluz se conserva únicamente como recurso provisional para demostrar la portada; sustituye la URL de `<source>` en `index.html` por un vídeo corporativo propio. No se incluye ni redistribuye el archivo de vídeo.

La estética está inspirada en los patrones y colores de jocarsa-iu; se trata de una adaptación de frontend, no de una integración completa de todos los módulos de accesibilidad de la referencia. `admin.html` es una maqueta sin persistencia. Para probar, sirve esta carpeta con un servidor HTTP.
