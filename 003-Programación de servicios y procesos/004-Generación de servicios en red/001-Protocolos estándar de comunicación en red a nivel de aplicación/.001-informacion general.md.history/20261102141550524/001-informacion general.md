protocolos:

Protocolo	Puerto habitual	Función
HTTP	80 TCP	Transferencia de páginas web
HTTPS	443 TCP	Navegación web cifrada
FTP	21 TCP	Transferencia de archivos
FTPS	990 TCP (implícito)	Transferencia de archivos mediante FTP y TLS
SFTP	22 TCP	Transferencia segura de archivos sobre SSH
SMTP	25, 587 TCP	Envío de correo electrónico
POP3	110 TCP	Descarga de correo electrónico
IMAP	143 TCP	Acceso y sincronización del correo
DNS	53 UDP/TCP	Traducción de dominios a direcciones IP
DHCP	67, 68 UDP	Asignación automática de direcciones IP
SSH	22 TCP	Acceso remoto seguro a servidores
Telnet	23 TCP	Acceso remoto sin cifrado
SNMP	161, 162 UDP	Monitorización de dispositivos de red
NTP	123 UDP	Sincronización de relojes
LDAP	389 TCP/UDP	Consulta de servicios de directorio
SMB	445 TCP	Compartición de archivos e impresoras
NFS	2049 TCP/UDP	Compartición de archivos en red
RDP	3389 TCP/UDP	Escritorio remoto
SIP	5060 UDP/TCP	Señalización de llamadas VoIP
MQTT	1883 TCP	Mensajería ligera para IoT
AMQP	5672 TCP	Mensajería entre aplicaciones
WebSocket	80/443 habituales	Comunicación bidireccional persistente
RTSP	554 TCP/UDP	Control de transmisiones multimedia
