Un programa es un conjunto de instrucciones que afectan a un procesador
El texto que escribimos es el código fuente del programa
Codigo fuente es legible por el ser humano
Código fuente genera código objeto
El código objeto genera código máquina (ejecutable)

Nosotros trabajamos con archivos de texto
El procesador trabaja con archivos binarios

Python es un lenguaje de muy alto nivel, 
y ejecuta su código contra la máquina virtual de Python
