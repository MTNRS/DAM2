2.-Su ejecución es: ./jocarsa-documentacion [entrada] [salida]
  Donde: 
  a)entrada es la ruta absoluta del directorio donde está vuestro código
  b)salida es la ruta absoluta del directorio donde queréis generar el informe
3.-Para cada unidad didáctica (proyecto final)
	a) Creáis una carpeta
  b) En esa carpeta ponéis 
  	* Vuestros ejercicios de esa unidad didáctica (subunidades)
    * El código de vuestro proyecto final de unidad
    * El archivo markdown en el cual explicáis cómo vuestro proyecto cumple con los criterios de evaluación
4.-Una vez que habéis reunido esos materiales en una carpeta
	a) ejecutáis el programa - os proporciona un informe markdown
  b) subís ese informe a la plataforma de formacion.jocarsa.com
